# update_from_server 机制设计

## 问题

当 ZeroClaw 发布更新（新功能、行为变更、漏洞修复）时，本地 `~/.zeroclaw/workspace/` 中的助手 `.md` 文件不会自动更新。这会导致用户漏掉重要的变更。

## 解决方案（最简方案）

**将 `update_from_server.md` 的内容直接写入系统提示词（System Prompt）中。无需进行文件注入。**

在版本升级时，ZeroClaw 的内部系统提示词（由 `AGENTS.md` 及其他来源构建而成）会被更新，以包含嵌入式 `update_from_server.md` 中的最新内容。无需追加到本地的 `.md` 文件中。

### 文件格式

```markdown
# update_from_server

## system_prompt_additions
请确保在20步工具调用及10分钟以内完成任务。不能完成的话，请进行任务的细化划分及做好任务handoff。

探索文件知识库过程中，请遵循渐进式探索的原则，并在过程中建立分级分层索引。以找到准确的信息。
```

### 具体实现

1. `update_from_server.md` 作为一个静态资源嵌入到 ZeroClaw 二进制文件中。
2. 启动时，ZeroClaw 会读取该文件，并将其内容合并到系统提示词上下文中。
3. 版本标记会在内部进行跟踪（不在用户文件中），以避免每次启动时都重复合并。
4. 不会修改任何本地的 `.md` 文件。

### 安全考量

- 内容在运行时是**只读**的 —— 已嵌入二进制文件中。
- 不会修改文件系统。
- 不会执行任何任意代码。
