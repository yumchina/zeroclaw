# Approval cancel-on-fanout follow-up Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 闭合 broker→channel `approval_id` 不联通 (I1)、cancel 索引粒度过粗 (I2)、DawnIM `cancel_approval` 空跑 (I5) 三个正确性问题，并同步把 lark `cancel_approval` 从默认空 impl 升级到 patch 原卡，让非 winner 卡片显式更新为「此请求已被处理 — 同意/拒绝/始终允许」。

**Architecture:** broker 生成 canonical `approval_id` 注入 `ChannelApprovalRequest`；channel 用 `(approval_id, recipient)` 复合 key 索引 pending；broker `fan_out` 跟踪 `(chref, recipient, channel)` 三元组，winner 选出后按 `(chref, recipient)` 精确派 cancel；cancel reason 经现有 fluent i18n 在 broker 端拼好后塞给 channel，channel 不感知 locale；dawn_im 发新 `INTERACTIVE_CARD` 落回原 topic，lark 复用现成 patch endpoint 把原卡变样。

**Tech Stack:** Rust 2024 edition, tokio async (`JoinSet`/`oneshot`/`RwLock`/`Mutex`), fluent-rs i18n, anyhow, async_trait, serde, JSON-RPC over WebSocket (dawn_im), Lark Open Platform HTTPS REST.

## Global Constraints

- 永远使用中文沟通 (CLAUDE.md / 全局 user instruction)。
- `cancel_approval` trait 签名最终形态：`async fn cancel_approval(&self, approval_id: &str, recipient: &str, reason: &str) -> anyhow::Result<()>`，默认 impl 返回 `Ok(())`。
- `ChannelApprovalRequest.approval_id: Option<String>` 带 `#[serde(skip_serializing_if = "Option::is_none")]`，向后兼容旧调用方。
- broker → channel `reason` 是已本地化好的字符串（fluent key `event-approval-cancelled-status` + 参数 `decision`）；channel 不再做任何 i18n。
- 卡片只显示决定（同意/拒绝/始终允许），不显示 decider 的 master_id / 名字；master_id 仅入 audit log（`identify_decider` 维持现状）。
- cancel 失败 best-effort：channel 返回 `Err`，broker `log!(WARN ...)` 后接续 return winner 决定，不阻塞主路径。
- DawnIM cancel 卡的 `topic + setting` 复用 `PendingApproval.topic` 里保存的原审批 topic，确保用户在原 topic 视图就能看到「已处理」更新。
- 提交风格沿用现有项目 `type(scope): message`（参考最近 commit：`feat(runtime/approval): ...`、`fix(runtime/agent): ...`、`docs(superpowers): ...`）。

```rust
        let mut alive_targets: Vec<(String, String, Arc<dyn Channel>)> = Vec::new();
        for (channel_ref, recipient) in targets {
            if let Some(ch) = self.directory.lookup(channel_ref) {
                let ch_clone = ch.clone();
                let chref = channel_ref.clone();
                let recipient_clone = recipient.clone();
                let req_clone = request.clone();
                set.spawn(async move {
                    let res = ch_clone
                        .request_approval(&recipient_clone, &req_clone)
                        .await;
                    (chref, recipient_clone, res)
                });
                alive_targets.push((channel_ref.clone(), recipient.clone(), ch));
            }
        }
        let mut winner: Option<(ChannelApprovalResponse, String, String)> = None;
        let timeout = self.approval_timeout;
        let deadline = tokio::time::Instant::now() + timeout;
        loop {
            tokio::select! {
                Some(joined) = set.join_next() => {
                    if let Ok((chref, recipient, Ok(Some(resp)))) = joined {
                        winner = Some((resp, chref, recipient));
                        break;
                    }
                }
                _ = tokio::time::sleep_until(deadline) => { break; }
                else => { break; }
            }
        }
        if let Some((ref resp, ref winning_chref, ref winning_recipient)) = winner {
            let reason = compute_cancel_reason(resp);
            for (chref, recipient, ch) in alive_targets.iter() {
                if (chref.as_str(), recipient.as_str())
                    != (winning_chref.as_str(), winning_recipient.as_str())
                {
                    if let Err(e) = ch
                        .cancel_approval(approval_id, recipient, &reason)
                        .await
                    {
                        ::zeroclaw_log::record!(
                            WARN,
                            ::zeroclaw_log::Event::new(module_path!(), ::zeroclaw_log::Action::Fail)
                                .with_outcome(::zeroclaw_log::EventOutcome::Unknown)
                                .with_attrs(::serde_json::json!({
                                    "approval_id": approval_id,
                                    "channel_ref": chref,
                                    "recipient": recipient,
                                    "error": format!("{e}"),
                                })),
                            "broker: cancel_approval failed (best-effort)"
                        );
                    }
                }
            }
        }
        set.shutdown().await;
        match winner {
            Some((r, c, rec)) => (Some(r), Some((c, rec))),
            None => (None, None),
        }
    }
```

```rust
    /// Replace the channel's ws_sink with a tap that captures outbound JSON-RPC
    /// frames into a Vec<String>. The tap is driven by a tokio::io::duplex pair:
    /// the channel writes into one half (the WsSink end), the test reads the
    /// other half. Returns the receiver task handle so the test can drain.
    async fn install_capture_sink(
        ch: &DawnIMChannel,
    ) -> Arc<tokio::sync::Mutex<Vec<String>>> {
        use futures_util::SinkExt;
        use tokio_tungstenite::WebSocketStream;
        use tokio_tungstenite::tungstenite::protocol::Role;

        let (client, server) = tokio::io::duplex(64 * 1024);
        let mut ws_server = WebSocketStream::from_raw_socket(server, Role::Server, None).await;
        let ws_client = WebSocketStream::from_raw_socket(client, Role::Client, None).await;
        let (sink, _stream) = futures_util::StreamExt::split(ws_client);
        *ch.ws_sink.write().await = Some(sink);
        let captured = Arc::new(tokio::sync::Mutex::new(Vec::<String>::new()));
        let captured_clone = captured.clone();

            use futures_util::StreamExt;
            while let Some(Ok(msg)) = ws_server.next().await {
                if let tokio_tungstenite::tungstenite::Message::Text(t) = msg {
                    captured_clone.lock().await.push(t.to_string());
                }
            }
        });
        captured
    }
```

```rust
//! End-to-end coverage for broker fan_out + cancel_approval wiring.
//! Uses lightweight in-process FakeChannel (duplicated minimally from
//! broker::tests since #[cfg(test)] items aren't reachable cross-crate).

use std::sync::{Arc, Mutex as StdMutex};
use std::time::Duration;

use async_trait::async_trait;
use tempfile::TempDir;
use zeroclaw_api::channel::{
    Channel, ChannelApprovalRequest, ChannelApprovalResponse, ChannelMessage, SendMessage,
};
use zeroclaw_infra::identity_store::IdentityResolver;
use zeroclaw_runtime::approval::{
    ApprovalBroker, ApprovalGrant, ApprovalGrantStore, BrokerDecision, BrokerRequestCtx,
    ChannelDirectory, Humanizer, SqliteGrantStore,
};

struct FakeChannel {
    name: String,
    respond_with: StdMutex<Option<ChannelApprovalResponse>>,
    delay: Duration,
    cancel_calls: StdMutex<Vec<(String, String, String)>>,
}

impl FakeChannel {
    fn new(name: &str, response: Option<ChannelApprovalResponse>, delay_ms: u64) -> Self {
        Self {
            name: name.into(),
            respond_with: StdMutex::new(response),
            delay: Duration::from_millis(delay_ms),
            cancel_calls: StdMutex::new(Vec::new()),
        }
    }
}

impl zeroclaw_api::attribution::Attributable for FakeChannel {
    fn role(&self) -> zeroclaw_api::attribution::Role {
        zeroclaw_api::attribution::Role::Channel(zeroclaw_api::attribution::ChannelKind::Cli)
    }
    fn alias(&self) -> &str { &self.name }
}

#[async_trait]
impl Channel for FakeChannel {
    fn name(&self) -> &str { &self.name }
    async fn send(&self, _: &SendMessage) -> anyhow::Result<()> { Ok(()) }
    async fn listen(&self, _: tokio::sync::mpsc::Sender<ChannelMessage>) -> anyhow::Result<()> {
        Ok(())
    }
    async fn request_approval(
        &self,
        _: &str,
        _: &ChannelApprovalRequest,
    ) -> anyhow::Result<Option<ChannelApprovalResponse>> {
        tokio::time::sleep(self.delay).await;
        Ok(self.respond_with.lock().unwrap().clone())
    }
    async fn cancel_approval(
        &self,
        approval_id: &str,
        recipient: &str,
        reason: &str,
    ) -> anyhow::Result<()> {
        self.cancel_calls.lock().unwrap().push((
            approval_id.to_string(),
            recipient.to_string(),
            reason.to_string(),
        ));
        Ok(())
    }
}

struct StaticDirectory(Vec<(String, Arc<dyn Channel>)>);
impl ChannelDirectory for StaticDirectory {
    fn lookup(&self, channel_ref: &str) -> Option<Arc<dyn Channel>> {
        self.0.iter().find(|(k, _)| k == channel_ref).map(|(_, v)| v.clone())
    }
}

struct EmptyIdentity;
impl IdentityResolver for EmptyIdentity {
    fn resolve(&self, _: &str, _: &str, _: bool) -> Option<String> { None }
    fn issue_code(&self, _: &str) -> Option<String> { None }
    fn redeem_code(&self, _: &str, _: &str, _: &str) -> Result<String, String> { Err("n/a".into()) }
    fn unbind(&self, _: &str, _: &str) -> bool { false }
    fn reverse_lookup(&self, _: &str, _: &str) -> Option<String> { None }
}

fn fresh_store() -> (TempDir, Arc<dyn ApprovalGrantStore>) {
    let tmp = TempDir::new().unwrap();
    let s = SqliteGrantStore::new(tmp.path()).unwrap();
    (tmp, Arc::new(s) as Arc<dyn ApprovalGrantStore>)
}

fn broker_with(
    dir: Arc<dyn ChannelDirectory>,
    grants: Arc<dyn ApprovalGrantStore>,
    superusers: Vec<String>,
    master_channel: Option<String>,
    timeout: Duration,
) -> ApprovalBroker {
    let su = Arc::new(superusers);
    let mc = Arc::new(master_channel);
    ApprovalBroker::new(
        grants,
        Arc::new(EmptyIdentity),
        dir,
        Arc::new(Humanizer::new(None, Duration::from_secs(10))),
        Arc::new(move || (*su).clone()),
        Arc::new(move || (*mc).clone()),
        timeout,
    )
}
```
